# Antigravity Universal Enterprise Visual Standard & Intelligence System

Production-grade standard applying globally to every project (websites, web/mobile apps, SaaS platforms, enterprise systems, dashboards, maps, data visualizations, 3D experiences, and interactive applications).

---

## Universal Visual Commands

When operating on visual assets, support these universal commands:

- `/visual-audit`: Automatically execute the 8-stage visual audit (Inventory → Quality → Consistency → Accessibility → Performance → Animation → 3D → Map Analysis → Improvement Plan).
- `/visual-clean`: Clean up existing media (remove artifacts, noise, blur, visual clutter, background distractions, lighting/color imbalances).
- `/visual-enhance`: Improve existing assets while preserving subject identity, architectural structure, and factual meaning.
- `/visual-restore`: Repair damaged, degraded, or low-resolution visual information.
- `/visual-upscale`: Increase usable resolution and detail without introducing synthetic artifacts.
- `/visual-create`: Generate new enterprise production assets when no existing asset is suitable.
- `/visual-edit`: Target-edit specific elements, backgrounds, or subjects without destructive overwrites.
- `/visual-animate`: Implement purposeful, accessible animations with motion design tokens and `prefers-reduced-motion` compliance.
- `/visual-3d`: Inspect, optimize, and integrate enterprise 3D models, scenes, and camera controls.
- `/visual-video`: Create or enhance cinematic video assets, demonstrations, and motion sequences.
- `/visual-map`: Audit and render cartographic/geographic data with strict geographic accuracy and visual hierarchy.
- `/visual-optimize`: Compress, convert (WebP/AVIF), lazy-load, and tune assets for 60 FPS performance.
- `/visual-consistency`: Verify icon systems, palettes, typography, and stylistic coherence across all application views.
- `/visual-accessibility`: Enforce WCAG 2.1 AA contrast, accessible labels/alt-text, and reduced-motion states.
- `/visual-performance`: Implement responsive srcset, skeleton/blur placeholders, and GPU-conscious rendering.
- `/visual-qa`: Run the 21-point Visual Quality Gate checklist.
- `/visual-overhaul`: Execute comprehensive end-to-end enterprise visual refresh of an entire project or screen.

## 1. Universal Visual Inspection & Classification

Before creating, replacing, modifying, or deleting visual assets, inspect the existing project.

Identify all images, photographs, illustrations, icons, logos, maps, charts, diagrams, infographics, 3D models/scenes, animations, motion graphics, videos, backgrounds, hero media, avatars, product imagery, school/building imagery, UI screenshots, decorative assets, and placeholders.

Classify each asset:
- `RETAIN`: Already meets enterprise production standard.
- `ENHANCE`: Improve existing asset while preserving its identity.
- `CLEAN`: Remove noise, artifacts, unwanted objects, and clutter.
- `RESTORE`: Repair damaged or degraded areas.
- `UPSCALE`: Increase usable resolution and clarity.
- `EDIT`: Target-modify specific portions of the asset.
- `ANIMATE`: Convert a static visual into purposeful motion.
- `CONVERT TO 3D`: Upgrade to an interactive or stylized 3D representation.
- `OPTIMIZE`: Compress, format, and optimize delivery performance.
- `REPLACE`: Replace when an asset cannot meet the enterprise standard.
- `CREATE`: Generate a new production asset when none exists.

## 2. Preexisting Image Cleanup & Preservation Workflow

Existing images must not automatically be replaced.

Preferred workflow:
```
ORIGINAL
   ↓
INSPECT (Artifacts, noise, blur, cropping, aspect ratio, color/exposure, contrast, branding)
   ↓
CLEAN
   ↓
RESTORE
   ↓
ENHANCE
   ↓
UPSCALE
   ↓
COMPARE WITH ORIGINAL
   ↓
QUALITY CHECK
   ↓
INTEGRATE
```

**Rule**: Preserve the original asset until the enhanced version has been verified. Never alter important factual information contained within an image merely to make it look better.

---

## 3. Image & Video Generation Standards

- Use the highest-quality available generation capabilities (Text-to-image, Image-to-image, Image enhancement/restoration/upscaling, Text-to-video, Image-to-video, Reference-based generation).
- **No Placeholders**: Never insert generic or low-quality placeholders when production-grade assets can be generated or refined.
- **Reference Preservation**: When using image-to-image on existing assets, preserve subject identity, product identity, architecture, and branding while improving detail, realism, and cleanliness.

---

## 4. Enterprise Animation & Motion Design System

- Animations must communicate purpose (navigation, feedback, orientation, hierarchy, transitions, state changes).
- Avoid excessive bouncing, random motion, excessive parallax, distracting loops, and blocking animations.
- Establish consistent tokens for entrance, exit, hover, focus, loading, modal, scroll, and micro-interactions.
- **Accessible Motion**: Strictly support `prefers-reduced-motion`, keyboard navigation, focus visibility, and screen-reader-compatible states. Critical functionality must never depend on animation.

---

## 5. 3D Visual Assets & Performance

- Treat 3D assets as enterprise production assets (inspect geometry, topology, materials, textures, lighting, scale, camera).
- Optimize for target devices: appropriate polygon counts, level of detail (LOD), compressed textures, lazy loading, and GPU-conscious shaders.
- Interaction: Provide intuitive rotate, zoom, pan, hover, selection, and layer visibility controls. Never make users fight the camera. If 3D does not materially improve the experience, use a high-quality 2D alternative.

---

## 6. Cartographic & Map Standards

- Prioritize geographic accuracy, legibility, consistent labeling, clear zoom hierarchy, accessibility, and performance.
- **Data Integrity**: Never fabricate geographic coordinates, boundaries, locations, roads, or landmarks. If data is incomplete, preserve uncertainty rather than inventing precision.
- **Visual Hierarchy**: Visually distinguish Primary (selected location, user location, destination), Secondary (nearby locations, categories, landmarks), and Reference (roads, boundaries, terrain) layers without decorative clutter.

---

## 7. Diagrams, Data Visualizations & Icons

- Charts, diagrams, graphs, timelines, and infographics must prioritize accuracy, readability, hierarchy, and accessibility over pure decoration.
- Icons must follow a coherent system with consistent stroke weight, geometry, corner radius, size, and optical alignment. Never mix disparate icon sets without deliberate purpose.

---

## 8. Enterprise Visual Language & Brand Conformance

- Every project must appear professional, intentional, consistent, trustworthy, refined, stable, and production-ready.
- Avoid hallmarks of unfinished applications: random gradients, generic AI imagery, excessive glassmorphism, inconsistent shadows, random border radii, excessive glow, uncontrolled motion, and inconsistent spacing.
- Always identify and conform to the project's logo, brand colors, typography, design tokens, and component system.

---

## 9. Responsive Visuals, Performance & Loading Experience

- Validate visuals across mobile, tablet, laptop, desktop, and large screens (cropping, scaling, text overlap, touch controls).
- Performance: Modern formats (WebP, AVIF), responsive `srcset`, lazy loading, asset compression, video poster frames, and CDN delivery.
- Loading: Never leave blank screens; provide skeletons, blur placeholders, or 3D loading indicators.

---

## 10. The 21-Point Visual Quality Gate

Before considering visual work complete, verify:

- [ ] Professional enterprise appearance
- [ ] Correct resolution
- [ ] Correct aspect ratio
- [ ] Clean imagery (no noise, artifacts, or distortion)
- [ ] Correct branding
- [ ] Correct color palette alignment
- [ ] Consistent typography
- [ ] Consistent icon system
- [ ] Purposeful, controlled animation
- [ ] Accessible animation (`prefers-reduced-motion`)
- [ ] Optimized 3D geometry and performance
- [ ] Correct cartographic/geographic data (zero fabricated coordinates)
- [ ] Visual hierarchy on maps and data visualizations
- [ ] Responsive behavior across all breakpoints (mobile to 4K)
- [ ] Delivery performance (WebP/AVIF, lazy loading, compression)
- [ ] Accessibility (WCAG 2.1 AA contrast, alt-text, labels)
- [ ] Cross-browser compatibility
- [ ] Mobile touch & gesture compatibility
- [ ] No visual artifacts or broken assets
- [ ] Zero placeholders in production views
- [ ] Consistent enterprise visual language

---

## 11. Browser Validation Requirement

Never approve visual assets based solely on source files:
1. Launch the application in a real browser.
2. Inspect desktop, tablet, and mobile views.
3. Test animations, maps, 3D scenes, and videos interactively.
4. Inspect loading states, contrast, and performance.

---

## 12. Enterprise Completion Rule

Visual work is COMPLETE only when:

$$\text{Visual Quality} + \text{Brand Conformance} + \text{UX} + \text{Accessibility} + \text{Responsiveness} + \text{Performance} + \text{Data Integrity} + \text{Browser Validation}$$

have all been verified.

The final question is:
> *"Does this visual improve the actual production application while conforming to its enterprise standards?"*  
> If the answer is no, continue improving it.
