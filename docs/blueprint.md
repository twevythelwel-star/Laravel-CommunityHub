# **App Name**: Community Hub

## Core Features:

- Homeowner Directory: Searchable directory of homeowners with contact information.
- Visitor Management: Homeowners can register and manage visitors with scheduled access times.
- Community Calendar: Shared calendar displaying community events and announcements.
- Admin Notifications: Admins can send push notifications for announcements and alerts. System admins can generate targeted notifications using an LLM tool, to automatically summarize long docs to smaller actionable items and assign them to specific communities.
- Warning System: Homeowners can submit warnings, and other homeowners can confirm or deny.
- Block List: Maintain a block list of unwanted visitors.
- Temporary Homeowners: Allow management of temporary homeowners (renters/guests) including specifying timeframes and access permissions. Can create temp users, with associated access end date. All expirations automatic.

## Style Guidelines:

- Primary color: Soft blue (#7EC4CF) for a calm, trustworthy feel. This provides a clean and welcoming aesthetic, appropriate for a community-focused app.
- Background color: Very light blue (#F0F8FF) to create a light and airy interface.
- Accent color: Muted green (#A0D6B4) for a subtle contrast that doesn't overwhelm the user.
- Body and headline font: 'PT Sans', a humanist sans-serif, combines a modern look and a little warmth or personality, so is suitable for headlines or body text.
- Use simple, clear icons for navigation and actions.
- Maintain a clean, uncluttered layout with intuitive navigation. Use a grid system for consistent spacing and alignment.
- Incorporate subtle transitions and animations to enhance user experience, but avoid distracting elements.
